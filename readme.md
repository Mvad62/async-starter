# Асинхронные операции с использованием `@Async` и пула потоков

## Задание

Необходимо создать конфигурацию для асинхронных операций с использованием аннотации `@Async` и настроить пул потоков через `ThreadPoolTaskExecutor`. Также нужно применить аннотацию `@Async` к методам, которые выполняют обращения к внешним сервисам.


Чтобы проверить, запустите приложение и вызовите метод `create` со следующими параметрами:
```text
create '{"productId": 123, "name": "Example Product", "productType": "Electronics", "qty": 2, "price": 99.99}'
```
