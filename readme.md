# Асинхронные операции с использованием `@Async` и пула потоков

## Задание

Необходимо создать конфигурацию для асинхронных операций с использованием аннотации `@Async` и настроить пул потоков через `ThreadPoolTaskExecutor`. Также нужно применить аннотацию `@Async` к методам, которые выполняют обращения к внешним сервисам.

## Шаги выполнения

1. Включите поддержку асинхронных операций в приложении.

2. Настройте пул потоков с использованием `ThreadPoolTaskExecutor`. Укажите количество потоков и параметры, такие как очередь ожидания задач.

3. Примените аннотацию `@Async` к методам, которые выполняют обращения к внешним сервисам, таким как:
    - `notificationService`
    - `vendorService`
    - `packageService`
    - `deliveryService`
    - `trailerService`

4. Запустите приложение и вызовите метод `create` со следующими параметрами:
```text
create '{"productId": 123, "name": "Example Product", "productType": "Electronics", "qty": 2, "price": 99.99}'
```
